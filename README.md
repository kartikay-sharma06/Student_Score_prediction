# Student Score Predictor - Flask Web Application

A Flask web application for predicting student final exam scores based on demographic and academic performance metrics.

## Quick Start (Windows)

1. Activate your virtual environment:
   venv\Scripts\activate

2. Install dependencies:
   pip install -r requirements.txt
   (Or run: pip install flask scikit-learn numpy)

3. Run the application:
   python app.py

4. Open in browser:
   http://127.0.0.1:5000

# Student_Score_prediction
Student Score Predictor is a Flask-based machine learning web app that predicts a student's expected score from academic and personal factors. It uses a trained ML model with data preprocessing and scaling, providing an interactive interface and performance insights to help understand factors affecting student performance.
